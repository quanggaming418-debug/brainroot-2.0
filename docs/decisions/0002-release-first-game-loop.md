# ADR-0002 — Build one complete learning loop before many games

- **Date:** 2026-11-20
- **Status:** PROPOSED
- **Context:** Deadline sơ tuyển 22–27/11 và Bảng B phải demo prototype thực tế; có hai line game, nhiều tham vọng chức năng.
- **Decision proposal:** R0 chỉ đưa 1 game hoạt động đầy đủ (start→play→feedback→finish). Catalog nêu đúng trạng thái game thứ hai.
- **Alternatives:** 5 game nửa hoàn chỉnh / một website chỉ có landing / một game full loop. Chọn một game full loop.
- **Consequences:** demo đáng tin, còn dư địa để xây Green Arena Lite như phần nâng cấp 24h; roadmap ngoài cuộc thi không bị bỏ.
- **Validation:** guest run on mobile and desktop, test records and sources.
